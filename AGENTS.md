# KirzKit Repository Instructions

When this repository's instructions are loaded, use KirzKit's intent-to-
execution model by default. Users may describe rough ideas or outcomes in
ordinary language; do not require a `$kirzkit` command, `/plan`, formal brief,
or user-selected skill or agent.

For each request, infer the desired outcome, relevant scope and constraints,
then inspect the relevant project context and capabilities. Use the smallest
useful route, read only the skills and agent guidance that apply, and ask only
when an unknown blocks safe/useful progress or materially changes the outcome.
Plan proportionally; delegate only when the host supports agents and work is
independent. Validate relevant changes and report evidence honestly.

For KirzKit repository work, consult `SKILL.md`, project rules, and relevant
skills/workflows as needed. Preserve existing user changes and follow the
repository's validation conventions.
